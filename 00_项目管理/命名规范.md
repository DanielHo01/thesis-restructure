# 学术项目文件命名规范

> 本项目所有文件严格遵循以下命名法则，确保机器可读性、时间追溯性及跨平台兼容性。

---

## 1. 核心公式

```
[日期]_[模块/作者]_[具体内容]_[版本号].[后缀]
```

## 2. 字段规范

| 字段 | 规范 | 示例 |
|------|------|------|
| **日期** | `YYYY-MM-DD`，置于最前 | `2026-03-15` |
| **分隔符** | 仅用下划线 `_`，**严禁空格** | `开题_报告_v1` |
| **版本号** | 草稿 `v1/v2`，提交版 `RC1`，定稿 `Final` | `_v2`, `_RC1`, `_Final` |

## 3. 正确示范 ✅

```
2025-10-06_开题报告_v6.doc
2026-04-10_知情同意书_Final.pdf
04_Hooper_LMM_Analysis.R
03_app_ga_rep_43.csv
P003_访谈初步编码备忘录_待核对.docx
```

## 4. 错误示范 ❌

| 错误写法 | 问题 |
|---------|------|
| `毕业论文(何天元)修改版 最新.doc` | 无日期、有括号、有空格 |
| `analysis final final 2.R` | 有空格、版本混乱 |
| `开题报告最终版2024.docx` | 日期格式不标准 |
| `研究二 数据 清洗.py` | 有空格 |

## 5. 特殊规则

### 5.1 脚本文件
- 使用序号代替日期（确保执行顺序）
- 格式：`[序号]_[描述].R` 或 `[序号]_[描述].py`

### 5.2 数据文件
- 原始数据：`[序号]_[描述]_Raw.csv`
- 清洗后数据：`[序号]_[描述]_Clean.csv`

### 5.3 图表文件
- 论文用图：`图X-Y_[描述].[png/pdf]`
- 分析探索图：`G[X]_[描述].[png/pdf]`

## 6. 禁止使用的字符

```
( ) [ ] { } ! @ # $ % ^ & * + = | \ / ? < > : ; " '
```

## 7. 版本号语义

| 版本标识 | 含义 |
|---------|------|
| `v1`, `v2`, `v3` | 草稿版本 |
| `RC1`, `RC2` | Release Candidate，提交审阅 |
| `Final` | 最终定稿 |
| `_revised` | 修订版 |

*本规范基于学术项目最佳实践制定*
