# Python 实验数据分析管线

固定链路：

```text
10_最终交付包/01_原始数据 → 00 清洗 → 01–07 主分析(run_all) → 08 ITT敏感性 → 11 补充计算
```

## 一键复现

```bash
pip install -r requirements.txt        # 或使用已配置的解释器
./run_full_pipeline.sh                 # 依次执行下列4步
PYTHON=/path/to/python ./run_full_pipeline.sh   # 指定解释器
```

等价的手动顺序：

```bash
python 00_clean_data.py                          # ① 清洗：01_原始数据/ → 清洗分析数据/
python run_all.py                                # ② 主分析：报告 01–07
python 08_ITT敏感性分析.py                        # ③ ITT敏感性：报告 08_*
python 11_补充计算_基线效应量推进标准.py           # ④ 补充计算：报告 11_*（先跑口径自检）
python 12_热身课次级偏移特征.py                    # ⑤ 偏移特征：报告 12_*
```

全部脚本在 requirements.txt 所列版本下端到端复现通过（2026-09-09 验证）。

## 统计口径（与论文一致）

- PP=24（AI=11，Self=13）；随机化36（AI=18/Self=18）；进入训练29；随机化后主要后测完成率 24/36（66.7%）。
- **随机化时点（2026-09-09确认）**：正式1RM前测（负荷-速度建档+1RM，36人全部完成）→ 力量分层 → 分层区组随机分组 → 其余T0基线测试（体成分、CMJ、SJ、IMTP、量表）→ 干预。因此仅1RM具备36人完整基线，ITT敏感性分析仅覆盖1RM；CONSORT口径见 `../05_分析说明/CONSORT核对/`。
- 主要结局：`Post ~ C(Group) + Pre + C(Stratum)`，Group 参照=Self组（AI−Self为正表示AI组更高）。
- Hooper：`Hooper_final ~ C(Group)*C(Sess, Poly) + (1|ID)`，REML。
- App–GymAware：热身课次级（88对）与Rep级（43对）分开分析；Bias=App−GymAware；ICC(2,1) 的95%CI用受试者级整簇bootstrap（10000次，种子20260909）。
- 效应量：Hedges' g（变化值口径，noncentral-t 精确95%CI）；另报标准化ANCOVA差值。
- 随机种子统一 20260909（bootstrap 与 MI），保证结果可复现。
