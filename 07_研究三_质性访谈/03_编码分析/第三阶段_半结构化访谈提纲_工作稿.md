# 第三阶段半结构化访谈提纲

## 一、访谈说明

本访谈用于了解受试者在4周下肢抗阻训练中的真实体验，重点关注训练负荷调节、疲劳与恢复、反馈理解、系统信任、操作负担和持续使用意愿。访谈采用半结构化方式，问题顺序可根据受试者回答灵活调整。

访谈开始前向受试者说明：

1. 本访谈仅用于研究，不评价个人训练表现；
2. 受试者可以拒绝回答任何问题，也可以随时终止访谈；
3. 访谈内容将匿名处理；
4. 经受试者同意后进行录音；
5. 研究人员不会在访谈中暗示某一种训练模式更好。

建议单次访谈时间为20至30分钟。访谈前记录受试者编号、组别、训练完成课次、是否发生自动减组或自主调整，以及是否同意录音。

## 三、共同访谈问题

### 3.1 总体训练体验

1. 回顾这4周训练，你对整个训练过程的总体感受是什么？
2. 哪些训练环节最容易完成？哪些环节比较困难或麻烦？
3. 训练过程中有没有出现你原本没有预料到的情况？
4. 如果重新参加一次类似训练，你最希望改变哪个部分？

可选追问：

- 这种困难是偶尔出现，还是反复出现？
- 困难主要来自训练计划、动作、负荷、设备还是时间安排？
- 这种困难是否影响了训练完成或出勤？

### 3.2 负荷选择与调整

1. 每次训练时，你是如何决定使用多大重量的？
2. 你觉得当天状态会影响重量选择吗？
3. 有没有出现过原计划重量不适合当天状态的情况？
4. 当你觉得重量太重或太轻时，通常会怎么做？
5. 你觉得自己能够准确判断“还可以完成几次”吗？

可选追问：

- 你主要依据训练感觉、动作速度、上一组表现还是训练计划？
- 你更担心重量过重，还是训练刺激不足？
- 你是否曾经因为不确定而保持原重量或提前停止？

### 3.3 疲劳与恢复

1. 训练过程中，你通常如何判断自己已经比较疲劳？
2. 你会根据疲劳程度改变重量、次数或组数吗？
3. 训练结束后，你如何评价本次训练对身体的影响？
4. 这4周中是否有特别疲劳或特别轻松的训练课次？
5. 睡眠、学习压力、肌肉酸痛或其他生活因素是否影响过训练？

可选追问：

- 训练前能否准确判断当天状态？
- 训练中状态变差时，什么因素帮助你做决定？
- 你是否认为训练后的疲劳与训练效果有关？

## 四、人工智能辅助训练组专门问题

### 4.1 速度反馈的理解

1. 第一次接触杠铃速度反馈时，你最直观的感受是什么？
2. 你能理解系统显示的速度信息吗？
3. 哪些速度信息对你最有帮助？
4. 有没有哪些信息让你困惑或不容易理解？
5. 训练过程中你会主动关注速度数据，还是主要等待研究人员提示？

可选追问：

- 你是否理解“速度变慢”意味着什么？
- 速度数据是否改变了你的发力方式、训练节奏或训练信心？
- 你更希望看到具体数字，还是简单的文字提示？

### 4.2 负荷调整建议

1. 系统给出增加、保持或降低重量的建议时，你通常如何判断是否执行？
2. 有没有过不完全相信系统建议的情况？
3. 如果系统建议与你自己的感觉不一致，你会听谁的？
4. 系统建议是否让你更容易决定下一组使用多大重量？
5. 你觉得系统建议是否足够清楚、及时和可执行？

可选追问：

- 有没有建议来得太晚？
- 有没有建议与实际动作感受不一致？
- 建议是否过于保守或过于激进？
- 是否需要研究人员额外解释？

### 4.3 自动减组与停组机制

1. 你是否注意到系统会根据当天状态调整训练量？
2. 如果系统提示减少训练组数，你会如何理解？
3. 你是否愿意按照系统提示执行？为什么？
4. 减少组数后，你觉得训练效果会受到影响吗？
5. 如果没有系统提示，你自己是否可能作出相同决定？

可选追问：

- 你更看重安全性、训练效率还是完成计划？
- 你是否担心系统错误地减少训练量？
- 如果系统说明减组原因，你会更容易接受吗？

### 4.4 系统信任与可用性

1. 你在多大程度上相信系统给出的速度和负荷建议？
2. 这种信任是从什么时候开始形成的？
3. 有没有哪次经历降低了你对系统的信任？
4. 你认为系统在什么情况下最可靠？
5. 使用过程中哪些操作最方便，哪些最麻烦？
6. 设备连接、摆放、准备和记录是否影响训练流畅性？
7. 如果没有研究人员在旁边，你能否独立使用？

可选追问：

- 你更相信设备数据、研究人员解释还是自己的感觉？
- 哪个环节最影响你对系统的整体评价？
- 如果只能改进一个功能，你会改什么？

### 4.5 持续使用意愿

1. 如果训练结束后仍可以使用这个系统，你愿意继续使用吗？
2. 哪些条件会让你愿意继续使用？
3. 哪些情况会让你停止使用？
4. 你认为系统更适合哪些人？
5. 你是否愿意为这个系统付费？什么功能最值得付费？

可选追问：

- 价格、便利性、反馈准确性哪个最重要？
- 没有研究人员监督时，你还会相信系统吗？
- 你会推荐给训练经验较少的人吗？

## 五、规范化自我指导组专门问题

### 5.1 RPE/RIR判断

1. 训练中你如何判断RIR或“还可以完成几次”？
2. 这种判断容易还是困难？
3. 哪些动作或训练状态下最难判断？
4. 你是否担心自己判断错误？
5. 你是否会因为不确定而选择保守重量？

可选追问：

- 接近力竭时是否更容易判断？
- 训练开始和后半程的判断是否不同？
- 是否希望获得速度或其他客观反馈？

### 5.2 缺少客观反馈的体验

1. 训练过程中没有实时速度反馈，对你有什么影响？
2. 你是否曾经希望知道杠铃移动速度或动作表现？
3. 你能否判断动作是否已经明显变慢？
4. 没有速度信息时，你主要依据什么决定是否继续？
5. 如果增加一种客观反馈，你最希望得到什么信息？

可选追问：

- 缺少反馈是否降低训练信心？
- 是否因此更依赖研究员、镜子或主观感觉？
- 没有速度信息让训练更简单，还是更不确定？

### 5.3 对数字化反馈的接受度

1. 如果未来可以使用速度反馈系统，你愿意尝试吗？
2. 你认为速度反馈可能带来什么好处？
3. 你认为它可能带来什么麻烦？
4. 你更希望系统给出数字，还是直接给出训练建议？
5. 在什么情况下你会继续选择传统自我调节？

## 六、两组共同的比较性问题

1. 训练中最重要的是重量、次数、速度、动作质量还是疲劳程度？为什么？
2. 训练计划和当天状态之间应该如何平衡？
3. 训练者应该完全自主决定，还是接受系统建议？
4. 数字化系统最适合帮助解决哪类训练问题？
5. 哪些训练决策不能交给系统自动完成？
6. 如果推广到普通健身人群，你最担心什么？
7. 对训练经验较少的人，系统需要增加哪些保护措施？

## 七、访谈结束问题

1. 关于这次训练，你还有哪些没有被问到但希望补充的内容？
2. 如果让你给研究团队一条改进建议，你最希望提出什么？
3. 你认为这种训练方式最值得保留的功能是什么？
4. 你认为最应该删除或修改的功能是什么？

## 八、访谈实施要求

1. 先使用开放式问题，再根据回答进行追问；
2. 不直接暗示AI组一定更好或Self组一定缺少反馈；
3. 不向受试者透露统计结果或研究者预期；
4. 对AI组和Self组使用共同问题加组别专门问题；
5. 记录受试者使用的原话和具体训练情境；
6. 访谈结束后立即补充访谈备忘录，包括情绪、停顿、重点事件和初步印象；
7. 不在访谈提纲中提前写入尚未完成的研究结论。

## 九、建议抽样维度

访谈对象可按照以下维度进行最大差异抽样：

- 组别：AI组和Self组；
- 基线力量层级：较高和较低；
- 训练完成情况：完成全部8次和未完成全部8次；
- AI组是否触发自动减组；
- 训练执行质量：相对较高和相对较低；
- AI组系统接受度：相对较高和相对较低；
- Self组自主调整频率：相对较高和相对较低。

抽样不应只选择最满意或训练完成最好的受试者，以免高估系统接受度和训练体验。
