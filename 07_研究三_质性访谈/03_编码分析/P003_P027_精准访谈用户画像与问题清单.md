# P003与P027精准访谈用户画像与问题清单

## 使用说明

以下画像依据目前清洗后的研究二数据制作，用于帮助研究者开展访谈。画像中的数字是受试者真实量化资料，不是访谈答案。访谈时应验证这些数字背后的真实经历，不能直接把画像中的解释当作结论。

两名受试者均属于Self组低力量层，训练年限为1至2年、每周训练约2次，均完成8次训练。两人适合用于补充当前Self组中“低基线、训练经验较少、但能够完成规范化自我指导”的受试者类型。

# 一、P003精准用户画像

## 1.1 量化资料

- 受试者编号：P003；
- 组别：Self组；
- 基线力量层级：低力量层；
- 年龄：22岁；
- 身高：172 cm；
- 体重：69.00 kg；
- 抗阻训练年限：1至2年；
- 平时训练频率：每周2次；
- 完成训练：8次，全勤；
- 自主调整次数：4次；
- 个体Hooper均值：20.63分；
- 总训练负荷：15200；
- 深蹲总负荷：11800；
- 总组数：28组；
- 总次数：102次；
- 全期平均sRPE：6.80；
- 总训练时长：750 min；
- 深蹲1RM：115.00 kg增至122.50 kg，变化+7.50 kg；
- CMJ：56.00 cm增至59.80 cm，变化+3.80 cm；
- SJ：51.20 cm增至54.50 cm，变化+3.30 cm；
- 训练自我效能：60分增至68分，变化+8分。

## 1.2 初步画像判断

P003是低力量层、训练经验较少但完成度较高的Self组受试者。其完成了全部8次训练，并有4次自主调整，说明其不是完全被动执行手册，而是确实尝试根据当天状态进行负荷调整。

与P015相比，P003的总体力量基础较低、训练年限较短，但训练结果呈现较为均衡的方向：1RM、CMJ和SJ均有提高。需要通过访谈确认，这种变化是否与其自主调整方式、对RIR的理解、训练负荷保守程度和动作质量意识有关。

P003的Hooper均值为20.63，处于中等水平，平均sRPE为6.80，说明其训练主观负荷可能并不低。4次自主调整是本次访谈的关键切入口，需要详细了解调整的时间、方向、原因和结果。

## 1.3 P003重点访谈问题

### A. 训练经验与规则理解

1. 你有1至2年抗阻训练经验，参加这次训练前对RIR的理解是什么？
2. 训练手册中哪一条规则最容易理解？哪一条最难执行？
3. 你认为自己是在“按照手册训练”，还是已经形成了自己的调整方法？
4. 训练开始前，你是否知道什么叫动作质量下降？

追问：

- 你能否举出一次具体课次？
- 当时使用了多少重量、完成了几次？
- 你当时为什么认为应该调整？
- 研究人员是否纠正过你的判断？

### B. 四次自主调整的逐次复盘

必须逐次询问P003的4次自主调整：

1. 第一次调整发生在第几次训练？
2. 调整前的计划重量、组数和次数是什么？
3. 最终做了什么调整：加重、减重、减少次数、增加休息还是保持重量？
4. 当时依据是什么：动作速度、RIR、呼吸、腿部酸胀、关节感觉还是心理状态？
5. 调整后，你认为动作质量发生了什么变化？
6. 如果有速度设备，你希望它支持还是否定当时的判断？

### C. 低力量层与负荷信心

1. 你是否会因为自己的力量基线较低而不敢加重？
2. 你更担心训练刺激不足，还是担心动作失败或受伤？
3. 看到其他人使用更大重量时，会不会影响你的负荷选择？
4. 如果系统告诉你可以加重，你会相信系统还是仍然保持保守？
5. 你认为Self组对低力量训练者来说是否足够安全？

### D. RIR与动作质量

1. 你通常如何判断还可以完成几次？
2. 你是否会把“动作变形后还能完成”算作RIR？
3. 你能否识别腰背代偿、膝内扣、起立减速或重心不稳？
4. 疲劳时你的RIR判断会变得更保守还是更激进？
5. 你是否曾经因为不确定而少做一次？

### E. 训练结果的主观解释

1. 你的1RM、CMJ和SJ都有提高，你认为主要原因是什么？
2. 你认为这次训练对力量和爆发力的影响一样吗？
3. 你认为自主调整在结果中起了多大作用？
4. 你是否认为低力量或训练经验较少的人更容易从规范化手册中获益？
5. 你对训练自我效能提高8分有什么感受？

### F. 对速度反馈的接受度

1. 如果未来使用GymAware，你最希望它帮助你判断什么？
2. 你希望只显示速度，还是直接给出加重、保持或减重建议？
3. 如果系统建议与你自己的感觉不同，你会怎么做？
4. 你是否担心速度数据让训练变得复杂？
5. 对你而言，速度反馈最大的价值是安全、加重信心、动作质量还是爆发力训练？

## 1.4 P003必须追问的具体事实

- 4次自主调整分别发生在哪些课次；
- 每次调整的方向和公斤数；
- 是否有一次因动作变慢而减少次数；
- 是否有一次因感觉良好而加重；
- 是否曾出现训练失败、疼痛或明显动作代偿；
- 是否理解“保持RIR”与“慢速硬顶”的区别；
- 1RM和跳跃三项结果提高是否改变其训练观念。

- 平时训练频率：每周2次；

## 2.2 初步画像判断

P027与P003同属低力量层、1至2年训练经验和8次全勤，但P027自主调整次数更多，为5次，Hooper均值也略高，为21.13分。其总训练负荷、深蹲总负荷、总组数和总次数低于P003，但1RM、CMJ和SJ的变化方向与P003相近。

P027适合重点了解“较高自主调整频率”和“较高主观恢复压力”之间的关系。需要确认这5次调整是否意味着更好的自我调节，也可能意味着训练过程中更频繁地感到不确定或状态波动。

## 2.3 P027重点访谈问题

### A. 五次自主调整的具体情况

1. 你能否按训练课次回忆5次自主调整？
2. 每次调整是加重、减重、减少次数还是延长休息？
3. 5次调整中，有几次是因为感觉疲劳？有几次是因为感觉状态好？
4. 调整前后动作速度和动作质量有什么变化？
5. 调整后你是否认为自己完成得更好？

### B. Hooper与训练状态

1. 你的个体Hooper均值为21.13，训练前最常出现的问题是什么？
2. 睡眠、压力、疲劳和肌肉酸痛中，哪个最影响你的负荷选择？
3. 当Hooper状态较差时，你是否更容易减重或减少次数？
4. 你能否在训练开始前判断当天是否适合按计划训练？
5. 如果有系统根据Hooper进行训练前预警，你会接受吗？

### C. 低力量层的安全和信心

1. 你认为自己能否独立判断深蹲重量是否合适？
2. 你是否曾经因为担心失败而选择保守重量？
3. 你是否曾经因为想完成计划而没有及时减重？
4. 你更希望得到数字反馈，还是直接获得负荷建议？
5. 如果系统提示你减重，你会觉得是帮助还是限制？

### D. RIR执行过程

1. 你认为自己实际保留了几次RIR？
2. 你判断RIR主要依据什么？
3. 你是否会把慢速完成的一次重复算作储备次数？
4. 你是否能够识别动作变形前的临界点？
5. 如果训练员现场观察你的动作，你认为其判断和自己的判断一致吗？

### E. 训练结果与自我效能

1. 1RM增加7.50 kg、CMJ增加3.60 cm、SJ增加3.00 cm，你认为主要原因是什么？
2. 训练自我效能增加7分，对你意味着什么？
3. 你是否因为完成8次训练而更相信自己能够完成力量训练？
4. 你认为结果来自训练手册、自己的调整还是训练规律？
5. 如果下一次没有研究人员监督，你能否继续执行同样规则？

### F. 对数字化速度反馈的需求

1. 如果使用GymAware，你希望系统纠正你的哪种问题？
2. 你是否希望系统在速度明显下降时主动提醒？
3. 如果系统建议与你的主观感觉不同，你会优先相信谁？
4. 你更需要“显示速度”，还是“直接告诉你下一步怎么做”？
5. 你认为设备会增加训练负担吗？

## 2.4 P027必须追问的具体事实

- 5次自主调整的课次、方向和原因；
- 调整是否与Hooper较高的训练日重合；
- 是否曾经出现训练状态差但仍完成原计划；
- 是否存在动作明显变慢但仍将其视为RIR；
- 是否有过关节不适或训练失败；
- 是否认为自己需要速度反馈；
- 训练自我效能提高7分是否来自训练成绩、完成训练还是安全感。

# 三、P003与P027的对照访谈问题

两人应额外询问以下相同问题，以便进行跨个案比较：

1. 你们都完成了8次训练，但自主调整次数不同。你认为自己为什么需要调整？
2. 你是否把自主调整看作能力，还是看作当天状态不稳定？
3. 你更希望训练手册给出原则，还是给出具体重量？
4. 你是否觉得低力量或训练经验较少的人更需要客观速度反馈？
5. 你认为自己能够区分“还可以做一次”和“还能用标准动作做一次”吗？
6. 你是否曾经把局部肌肉酸胀当成训练效果？
7. 如果有速度设备，你认为它会改变你的自主调整次数吗？
8. 你认为系统应该给建议，还是强制停止？
9. 你认为训练结果更重要，还是训练过程中的安全感和掌控感更重要？
10. 你是否愿意把这套规范化自我指导方法带到日常训练中？

# 五、建议的访谈顺序

## P003

先询问4次自主调整的具体事实，再询问RIR、训练结果和速度反馈需求。P003的重点是：

```text
较少调整次数 + 三项体能均有改善 + 中等Hooper
```

## P027

先询问5次自主调整和较高Hooper，再询问RIR、自我效能和速度反馈需求。P027的重点是：

```text
更多调整次数 + 较高恢复压力 + 三项体能均有改善
```

## 不能提前设定的结论

不能提前认为：

- P003和P027都准确掌握了RIR；
- 自主调整次数越多，训练效果越好；
- 低力量训练者一定需要速度设备；
- 两人的体能改善来自规范化手册；
- 两人的访谈能够代表全部低力量层Self组。

最终只能根据实际录音和逐字稿判断这些问题是否形成共同主题。
