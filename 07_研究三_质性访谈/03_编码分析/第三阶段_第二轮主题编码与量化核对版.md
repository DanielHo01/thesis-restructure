# 第三阶段第二轮主题编码与量化核对版

## 一、核对范围与证据等级

本轮已将目前收到的受试者访谈内容与现有清洗数据、训练汇总数据、自动减组资料和接受度数据进行对照。当前工作区没有受试者访谈录音原文件，因此本轮不能完成语音层面的逐字稿核验，只能完成“访谈文字—量化数据—训练记录口径”的核对。

证据等级分为：

- A级：访谈陈述与现有量化数据直接一致；
- B级：访谈主题与量化结果方向一致，但具体事件仍需训练日志核对；
- C级：受试者主观解释或假设性判断，不能作为客观结果；
- D级：目前数据无法验证，需要保留为待核对内容。

### 2.2 可以确认方向但不能确认事件细节的内容

- 受试者所说的“力量增加”“跳跃变化”“全勤”与主分析数据一致；
- 受试者所说的“系统接受度较高或较低”与AI组个体SUS、PU、Trust和Intention方向一致；
- P010和P016确实属于自动减组相关受试者，但自动减组发生的具体课次、组数和界面提示文字需要与事件档案逐项核对；
- P003和P027确实分别有4次和5次自主调整记录，但每次调整的具体方向和课次仍需与训练记录逐项对应；
- P025、P004、P018和P014关于训练结果的个体数字基本与数据一致，但其对结果原因的解释属于主观归因。

### 2.3 不能由当前数据确认的内容

以下内容不能直接视为客观事实：

- 某一次训练的具体速度数值；
- 某一次动作是否真的出现膝内扣、骨盆旋转或腰部代偿；
- 某次自动减组是否确实避免了潜在损伤；
- 某名受试者的体能提高是否由系统、手册、饮食或睡眠单独造成；
- “神经疲劳”“中枢疲劳”“神经系统被掏空”等生理解释；
- 系统建议是否一定过于保守；
- 如果当时完成全部组数，结果是否一定更好；
- 如果当时使用速度反馈，结果是否一定不同。

## 三、第二轮主题编码

### 主题一：训练者需要的不是同一种“反馈”

#### 核心命题

AI组和Self组都表达了对反馈的需求，但需求类型不同。部分受试者需要系统帮助加重和突破平台期，部分受试者需要系统提供安全边界，另一些受试者只希望系统记录和验证自己的感觉。

#### 子主题

1. 加重决策反馈：P025、P004；
2. 安全减量反馈：P010、P016、P027；
3. 速度纠偏反馈：P015、P021；
4. 疲劳监测反馈：P012、P014；
5. 自我感觉验证：P013；
6. 训练结果记录：P018、P014。

#### 量化整合

AI组PU和Trust整体较高，说明系统价值容易被认可，但SUS均值约65分，说明反馈价值认可不等于操作体验和智能体验达到较高水平。

### 主题二：规范化自我指导的关键不是“有没有仪器”，而是RIR是否被正确执行

#### 核心命题

Self组受试者的体验差异表明，RIR规则可能产生不同结果。P013、P012、P014能够把动作质量和关节反馈纳入RIR判断；P015、P021则分别表现出接近力竭和慢速硬顶倾向。P003和P027显示低力量受试者可以学习规则，但需要更多具体动作标准。

#### 子主题

1. RIR作为动作质量边界：P003、P013、P027；
2. RIR被意志力和好胜心污染：P015；
3. RIR被慢速硬顶重新定义：P021；
4. 经验型保守RIR：P012、P014；
5. RIR需要情境化指南：P027。

#### 量化整合

Self组总次数高于AI组且p=0.035，但该结果不能直接证明Self组训练质量较低。访谈提示，部分Self组受试者可能将完成次数、局部酸胀或慢速硬顶视为有效刺激，另一些受试者则能够主动停止并保护动作质量。

### 主题三：自动减组是安全规则，也是训练意义的重新协商

#### 核心命题

自动减组的意义并不固定。P010经历了从即时失败感到事后保护感的转变；P016则在认可安全性的同时担心训练刺激不足；P004、P018等没有实际触发者主要表达假设性态度。

#### 子主题

1. 即时被限制感：P010、P016；
2. 事后安全感：P010；
3. 训练剂量减少疑虑：P016；
4. 对规则刚性的担忧：P018；
5. 对强制约束的期待：P010；
6. 进取模式与保护模式需求：P016。

#### 量化整合

自动减组事件总数为4次，数量较少，不能检验其对体能结局的影响。访谈可以解释自动减组的主观意义，但不能证明其降低了实际损伤风险。

### 主题四：系统信任建立在“建议—结果”一致和安全体验上

#### 核心命题

P025、P004主要通过成功加重或流程顺畅建立信任；P010和P016主要通过安全保护形成信任；P018则认为系统测量理念有价值，但整体智能体验不足。系统信任不是单一维度。

#### 子主题

1. 成功加重形成信任：P025、P004；
2. 安全保护形成信任：P010、P016；
3. 设备专业感形成信任：P025、P004；
4. AI预期落差削弱信任：P018；
5. 关节感觉优先于算法：P012、P014；
6. 数据验证而非决策替代：P013。

### 主题五：低经验者需要行动建议，高经验者需要自主权

#### 核心命题

P003、P027、P010更希望系统直接告诉自己下一步怎么做；P012、P013、P014则更倾向于保留判断权，希望把设备作为参考、验证或疲劳监测工具。

#### 量化整合

该主题与训练年限、基线水平和训练目标有关，不能简单按照AI组和Self组二分。后续正式研究应考虑训练经验和基线力量的分层或交互作用。

### 主题六：训练结果与工具评价相互独立

#### 核心命题

P018的CMJ变化较明显但SUS、PU、Trust和Intention较低；P016系统信任和有用性较高但体能变化有限；P015力量提高但爆发力变化不佳；P013和P027三项体能均有提高但仍有不同的自主调节体验。

#### 解释意义

不能用体能结果代替系统评价，也不能用系统评价代替干预效果。应分别报告：

- 工具测量层；
- 训练执行层；
- 体能适应层；
- 心理体验层。

### 主题七：生活状态是训练决策的重要背景

#### 核心命题

P010强调睡眠和课业压力，P027强调作息不规律，P018和P014分别强调运动负荷与生活自律。受试者并不把训练理解为脱离生活环境的单独事件。

#### 量化整合

Hooper模型显示课次主效应显著，但组别×课次交互不显著。访谈可以帮助解释Hooper变化可能涉及的睡眠、课业、运动和恢复背景，但不能用个案生活经历推断整体Hooper机制。

## 四、AI组与Self组的轴心比较

### AI组主要体验结构

```text
客观数据输入
→ 系统建议或自动规则
→ 训练者执行、接受或质疑
→ 安全感、掌控感或受限感
```

AI组的核心矛盾是：

```text
系统保护与训练刺激之间的平衡
```

### Self组主要体验结构

```text
主观感觉和手册规则
→ 自主解释
→ 自主调整
→ 训练质量或训练风险
```

Self组的核心矛盾是：

```text
自主权与主观判断偏差之间的平衡
```

## 五、反例分析

### 反例一：AI系统并未让所有人都觉得好用

P018的体能变化较明显，但系统可用性和接受度评分相对较低，说明工具效果和工具体验可以分离。

### 反例二：Self组并非都存在RIR判断问题

P013、P012和P014表现出较强的动作质量意识和保守调节能力，说明不能把Self组整体描述为不准确或盲目。

### 反例三：自动减组并不一定被所有人视为积极

P010事后认可保护作用，P016仍担心训练刺激不足，说明自动减组的意义取决于训练者目标和对训练质量的理解。

### 反例四：高基线训练者并非完全拒绝工具

P012和P014虽然强调自主权，但仍认可疲劳监测、赛后分析或数据验证的价值。

## 六、量化—质性整合结论（暂定）

1. 量化结果显示AI组总体训练负荷未显著增加，访谈提示AI的潜在作用可能是调整负荷结构、减少决策不确定性和设置安全边界，而不是简单增加训练量；
2. Self组总次数较高，访谈显示部分受试者可能将重量、完成次数或局部酸胀视为训练有效性，但另一些受试者能够通过RIR和动作质量控制训练；
3. AI组训练自我效能较高，访谈提示安全感、掌控感、客观反馈和决策确定性可能是潜在解释，但不能进行因果确认；
4. AI组SUS低于较高可用性参考水平，访谈显示设备形态、界面解释、流程衔接和AI预期落差可能共同影响可用性；
5. APP与GymAware一致性较高，但访谈显示测量准确、指导价值、操作体验和长期使用意愿是四个不同问题；
6. 训练经验和基线力量可能影响用户对系统的需求类型，后续正式研究应考虑分层或效应修饰。

## 七、当前编码结论的边界

本轮结果是第二轮主题编码，不是最终质性结果。正式结果还需要：

- 核对原始录音和逐字稿；
- 核对P003、P027的自主调整明细；
- 核对P010、P016自动减组事件；
- 核对P025、P004、P018等具体课次叙述；
- 完成研究者之间或导师复核；
- 形成主题定义和排除标准；
- 判断新增资料是否继续产生新主题；
- 进行最终主题饱和判断。
