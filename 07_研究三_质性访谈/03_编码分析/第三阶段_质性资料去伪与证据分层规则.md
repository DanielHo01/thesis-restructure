# 第三阶段质性资料去伪与证据分层规则

## 一、总原则

本研究对访谈资料中的客观数据、动作技术判断、损伤预防推断和生理机制解释进行严格分层。受试者对上述内容的表述仅作为反映其心理预期、技术焦虑、训练信念和归因风格的叙事材料予以采纳。真实负荷参数、动作完成度和生理结局，以GymAware、SmartSpeed及实际训练日志的原始测量记录为准，不能以主观叙事替代客观测量或因果推论。

## 二、五类资料的编码处理

### 1. 微观速度数值和速度损失

受试者回忆的具体速度数值、速度损失比例和阈值，只编码为：

- 受试者对速度变化的主观感知；
- 速度反馈带来的信心或不安；
- 受试者对系统建议的理解。

除非能够在GymAware Rep级原始CSV和训练记录中逐项对应，否则不得将其写为实际速度事实。

推荐写法：

> 受试者主观感知到速度保持在较高区间，并将这种感知与后续加重信心联系起来；其访谈中提及的具体速度数值不作为客观测量结果报告。

### 2. 动作技术形态和代偿

“膝内扣”“骨盆旋转”“腰部代偿”“早安式深蹲”等内容编码为：

- 受试者对动作技术劣化的主观觉察；
- 疲劳状态下的动作控制担忧；
- 对动作安全的主观判断。

由于本研究未同步采集三维动作捕捉、测力台动力学或表面肌电，不能将其写成经运动学或动力学证实的技术异常。

### 3. 自动减组和损伤预防

自动减组事件可以依据系统记录确认；但“减组避免了损伤”“如果继续一定会受伤”等表述属于反事实和主观归因，只编码为：

- 自动减组带来的即时安全感；
- 训练者对系统保护功能的信任；
- 训练计划未完成带来的失落感；
- 对风险和训练刺激之间关系的重新理解。

不得写成“系统预防了运动损伤”，除非有相应的临床或伤病结局证据。

### 4. 体能结果的因果归因

受试者将1RM、CMJ或SJ变化归因于速度反馈、RIR、自我努力、饮食、睡眠或作息时，只编码为受试者的主观归因风格。正式讨论中必须同时考虑：

- 基线能力；
- 测试熟悉效应；
- 渐进负荷和训练剂量；
- 神经肌肉适应；
- 生活方式；
- 个体差异。

推荐写法：

> 受试者主观上认为速度反馈帮助其突破了心理瓶颈；但本研究设计不能排除测试熟悉效应、训练负荷变化和其他未控制因素对体能变化的影响。

### 5. 中枢神经疲劳和生活压力

受试者使用“中枢神经疲劳”“神经放电不足”“神经系统没有激活”等表述时，应还原编码为：

- 主观感知疲劳；
- 睡眠不足；
- 课业或生活压力；
- 肌肉酸痛；
- 注意力下降；
- 起杠沉重感；
- 当日神经肌肉表现下降的主观解释。

本研究未采集CK、皮质醇/睾酮比值、EEG或TMS等指标，因此不能对中枢或外周疲劳作生化或神经生理学确认。

## 三、正式论文中的证据标记

| 资料类型 | 可写成 | 不可写成 |
|---|---|---|
| 访谈回忆的速度 | 受试者感知速度变化 | 实际速度为某数值 |
| 主观动作觉察 | 受试者觉察到动作控制变差 | 已证实发生膝内扣或动力学失衡 |
| 自动减组体验 | 减组增强安全感 | 减组避免了损伤 |
| 受试者归因 | 受试者认为系统帮助其提高 | 系统导致体能提高 |
| “神经疲劳”用语 | 主观疲劳和生活压力体验 | 已证实中枢神经疲劳 |
| 个体案例 | 个案体验和可能机制 | 代表全组或证明因果 |

## 四、质性结果推荐表述

质性结果应优先报告：

1. 受试者如何理解训练反馈；
2. 受试者如何作出训练决策；
3. 受试者如何解释疲劳、风险和训练质量；
4. 受试者如何建立或拒绝系统信任；
5. 受试者如何看待自主权与算法建议；
6. 这些体验如何与量化结果相互解释。

质性结果不应直接承担：

- 速度测量的客观验证；
- 动作技术的生物力学验证；
- 运动损伤预防的因果证明；
- 中枢神经疲劳的生理学诊断；
- 训练效果的单一机制解释。
