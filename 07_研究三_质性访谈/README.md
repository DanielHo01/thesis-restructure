## 核心范畴与主题（第三轮精炼结果）

### 核心范畴
**训练者如何在客观反馈与自主判断之间协商训练决策。**

### 六大最终主题
1. 反馈将训练决策从"凭感觉"转化为"有依据的调整"
2. RIR能否转化为动作质量边界，决定自我指导的有效性
3. 算法化停组在安全保护和训练刺激之间形成张力
4. 系统接受取决于价值、可用性和自主权的共同平衡
5. 训练经验和基线水平影响反馈需求
6. 训练结果、系统评价和安全体验属于不同证据层面

### 五类跨个案类型
1. **积极接受型**（P025、P004）
2. **安全依赖型**（P010、P016）
3. **批判性接受型**（P018、P012、P014）
4. **规则内化型Self组**（P003、P013、P027）
5. **负荷导向型Self组**（P015、P021）
